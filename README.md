# Patch-DELTARUNE-romana
Aplicație care modifică fișierele jocului DELTARUNE pentru a putea instala și juca modul mai ușor și mai rapid. Este făcut în limbajul de programare Nim cu biblioteca `wNim`
Când lansezi aplicația, pe ecran va apărea un terminal. Acel terminal este folosit în cazul în care sunt erori.


## Ce înseamnă fiecare variabilă
`foldel` - **fol**der **del**tarune<br>
`locfin` - **loc**ație **fin**ală<br>
`jocfol` - **joc** **fol**der<br>
`imaginepgr` - imagine **p**ro**gr**am<br>
`imgpgr` - înseamnă același lucru ca variabila de mai sus<br>
`folderprin` - folder **prin**cipal<br>
`process_chselect` - procesul din cmd pentru a da patch la data.win-ul cu selectarea capitolelor<br>
`jsonuri` - locația fișierelor json cu dialogurile din joc
